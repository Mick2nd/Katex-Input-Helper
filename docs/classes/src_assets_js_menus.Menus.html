Class Menus

Supports various kinds of Menus. Part of this class is a menu description to be used by all kinds of applications.

Requires the following integrations:

  • Desktop main menu bar
  • Tablet main menu
  • Phone side menu
  • Insert context menu (of Editor)
  • View context menu
