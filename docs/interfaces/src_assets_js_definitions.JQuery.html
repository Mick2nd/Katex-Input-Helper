  • attr(attributeName, value_function): this

  • Set one or more attributes for the set of matched elements.

    Parameters

    • attributeName: string

      The name of the attribute to set.

    • value_function: string | number | ((this: TElement, index: number, attr: string) => string | number | void)

      @param value_function

      • value — A value to set for the attribute. If null, the specified attribute will be removed (as in removeAttr .removeAttr()).
      • function — A function returning the value to set. this is the current element. Receives the index position of the element in the set and the old attribute value as arguments.

    Returns this
